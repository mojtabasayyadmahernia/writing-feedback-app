# Worth the Pause: Annotated Sample

A worked example of the idea-discovery annotation guidelines, using an invented task, outline and paragraph on the topic of "working from home".

**Note.** The task prompt is included because the guidelines count the task as content the writer already had. Burst boundaries are invented, since real keystroke data is needed to decide discovery.

## 1. Sample material

### Task prompt

*In order to be productive, it is better for employees to work from home rather than in the office.*

### Outline (as transcribed)

- O1 I think working from home is mostly better
- O2 no commuting so more free time
- O3 fewer interruptions at home, helps concentration
- O4 But people can feel isolated
- O5 harder to learn from colleagues
- O6 hybrid might be best?

### Produced text

About 300 words, as the annotator sees it. Deleted text is struck through.

> (1) Working from home has become common in many companies. (2) Since the pandemic, millions of employees spend at least part of their week at home. (3) For many people, this change has been welcome. (4) Several studies have found that remote workers complete more tasks per day than office workers. (5) I will first consider some of the advantages. (6) Because they no longer commute, employees have more free time. (7) For example, many save about an hour each day, which they can spend resting or with their families. (8) Many can choose when to work, so they can schedule difficult tasks for the hours when they think most clearly. (9) There are fewer interruptions at home. (10) This helps concentration on demanding tasks, such as writing reports or analysing data. (11) However, workers who spend every day alone can feel isolated, and isolation tends to lower motivation. ~~Isolation also makes it harder to learn from colleagues~~ (12) As a result, the productivity that home working promises may never be fully realised. (13) Because they are isolated, home workers also find it harder to learn from colleagues, since much of this learning happens through informal conversations at the office. (14) Video calls can replace some of this contact, but they rarely produce the unplanned exchanges in which colleagues share advice. (15) Over time, missing these exchanges can leave home workers less skilled than colleagues who come into the office every day. (16) New employees suffer most, because they have not yet built a network of contacts. (17) Without a network, a new employee may not even know whom to ask for help. (18) I would argue that at least some meetings should take place in the office rather than at home. (19) A hybrid arrangement may therefore be best, since employees would keep most of their free time and still see colleagues regularly. (20) In short, the real question is how employees' weeks should be divided.

## 2. Stage one: task and outline

These annotations are fixed before the text is read.

### Task

| | Content | Configuration / realisation |
|---|---|---|
| T1 | (someone) is productive | Relational: Carrier unspecified; Attribute *productive* |
| T2 | for employees to work from home rather than in the office is better | Relational: Carrier embedded clause; Attribute *better* |
| TR1 | T2 → T1 | Purpose (means → purpose); *in order to*; env A |
| TR2 | from home — in the office | Variation: *in the office* replaced by *from home*; *rather than*; env C |

### Outline elements

| Item | Element and configuration |
|---|---|
| O1 | **E1** Relational: Carrier *working from home*; Attribute *mostly better*. *I think* is writer-projecting, so it is not annotated |
| O2 | **E2** *no commuting*: nominalised material figure; Actor unspecified; polarity negative. **E3** *more free time*: possessive; Carrier unspecified |
| O3 | **E4** Existential: Existent *fewer interruptions*; *at home* is a place, so part of the element. **E5** *concentration*: nominalised mental figure; Senser unspecified |
| O4 | **E6** Relational: Carrier *people*; Attribute *isolated*; modality *can* |
| O5 | **E7** Relational: Carrier embedded *to learn from colleagues* (learner unspecified); Attribute *harder* |
| O6 | **E8** Relational: Carrier *hybrid* (nominalised; participants unspecified); Attribute *best* |

### Outline relations

| | Terms | Type | Realisation | Env. |
|---|---|---|---|---|
| R1 | E2 → E3 | Cause | *so*, within one item | A |
| R2 | E4 → E5 | Cause | *helps* | F |
| R3 | R2 — E6 | Adversative | *But*; scope rule links it to O3, which realises R2 | B |

Points to note:

- O1, O5 and O6 contain no relation, because their comparatives and superlatives have no expressed standard.
- **Nothing links O4 and O5.** Isolation and learning are only juxtaposed, so no relation is annotated between them (§4.4). This matters later.

## 3. Stage two: the produced text

The annotator only marks relations as EXISTING or NEW. The NEW-TERM, ADDITIVE and UREL labels shown below are added afterwards from the burst boundaries in [section 4](#4-linking-to-bursts-and-outcomes), as in the guideline examples.

| s | Unit | Code | Reasoning |
|---|---|---|---|
| 1 | Working from home has become common… | UNEW | It shares a participant with T2, but no relation is expressed, so it is related to no available content |
| 2 | millions of employees spend… at home | UNEW | New figure; *at home* is a place, so part of the element |
| 2 | Since the pandemic | NEW-TERM | Temporal, env D (event noun); both terms are new |
| 3 | this change has been welcome | UNEW | The Attribute is a quality, so the clause construes one state, not a relation |
| 4 | Several studies have found that | UNEW | The source is not the writer, so the clause is annotated; projection itself is not a relation |
| 4 | remote workers complete more tasks… than office workers | UNEW; NEW-TERM | Comparison, env H; both terms are new |
| 5 | I will first consider some of the advantages | not annotated | About the writer's own text; *first* is internal conjunction |
| 6 | they no longer commute / employees have more free time | PLAN (E2, E3) | The text fills in E2's and E3's unspecified participants |
| 6 | Because | EXISTING | Same as R1: cause, E2 → E3 |
| 7 | many save about an hour each day | ELAB | New; linked to available content only by exemplification |
| 7 | For example | NEW-TERM | Exemplification, env B: R1 → new element |
| 7 | which they can spend resting or with their families | ELAB; NEW-TERM | Non-defining relative clause, so elaboration (env A). For the element code, the preceding clause counts as available. For the relation code, it does not, because both are in the same burst. *or* is also NEW-TERM |
| 8 | Many can choose when to work, so they can schedule… | UNEW ×2; NEW-TERM | Cause between new figures. *for the hours…* has a time as complement, so it stays inside the element |
| 9 | There are fewer interruptions at home | PLAN (E4) | |
| 10 | This helps concentration on demanding tasks | PLAN (E5); EXISTING | *This* refers to E4. Same as R2 |
| 10 | such as writing reports or analysing data | ELAB; NEW-TERM | Exemplification, env C, with new instances |
| 11 | However | EXISTING | The preceding sentence realises R2 and the clause it introduces is E6. This is the same pairing as R3 |
| 11 | workers who spend every day alone can feel isolated | PLAN (E6) | The relative clause is embedded |
| 11 | isolation tends to lower motivation | UNEW; NEW-TERM | Cause, env F: E6 → *motivation*, which is new |
| 11 | and | NEW-TERM | Its second term is the relation just completed |
| del. | ~~Isolation also makes it harder to learn from colleagues~~ | PLAN (E7); **UREL** | Cause, env F: E6 → E7. Both come from the outline but were never related there. The text was deleted, but the relation was still established (§6.2) |
| 12 | As a result | **UREL** | Cause, env B. Term 1 is the isolation → motivation relation. For term 2, the agnation rule applies: the clause shows an available participant, *productivity* (T1), undergoing an effect, so the term is T1. No relation between these terms is registered |
| 12 | the productivity that home working promises may never be fully realised | PLAN (T1) | See [gap 4](#6-gaps-found-while-annotating) |
| 13 | Because they are isolated, home workers… find it harder to learn from colleagues | REWORK (E6, E7); EXISTING | E6 → E7 was registered from the deleted text. **Without the deleted text, this sentence would have been the discovery** |
| 13 | also | ADDITIVE | External addition (a second effect of isolation). Both terms are available |
| 13 | since much of this learning happens… at the office | UNEW; NEW-TERM | Cause with a new cause term; *at the office* is a place, so part of the element |
| 13 | through informal conversations | NEW-TERM | Means, env D; the complement is an event noun |
| 14 | Video calls can replace some of this contact, but they rarely produce… | UNEW; NEW-TERM ×3 | Variation (env F), cause (env F) and adversative all involve *video calls*, which is new in this burst. *rarely* is modality, not polarity |
| 15 | missing these exchanges can leave home workers less skilled than… | UNEW; NEW-TERM ×2 | Cause (env F) and comparison (env H) with new terms; *Over time* is part of the element |
| 16 | New employees suffer most, because… | UNEW ×2; NEW-TERM | The link to s13–15 is only implied |
| 17 | Without a network, a new employee may not even know… | UNEW | *Without a network* has an entity complement, so it is part of the element. The link to s16 is lexical only |
| 18 | I would argue that | not annotated | Writer-projecting |
| 18 | at least some meetings should take place in the office | UNEW | New; related by variation, which is extension |
| 18 | in the office rather than at home | **UREL** | Same terms and subtype as TR2, but the direction is reversed: home is now replaced by office (§6.8) |
| 19 | A hybrid arrangement may… be best | PLAN (E8) | |
| 19 | therefore | NEW-TERM | Cause: s18 → E8. s18 was typed in the same burst. **With a pause between s18 and s19, this would be UREL** |
| 19 | since employees would keep… free time and still see colleagues… | UNEW; NEW-TERM ×2 | *keep* triggers the agnation rule, so the term is E3. *and* joins E3 to *see colleagues* (new), and *since* takes that new addition as its term |
| 20 | In short / the real question is how… | NEW-TERM; ELAB | Linked to available content only by clarification |

## 5. The steps in simple words

1. **List what the writer had before writing.** Take the task and the outline and break them into single ideas, each one "who does or is what". Also note every link between ideas that is spelled out in words, such as *because*, *but*, *so* or *rather than*. Do this before you read the essay, then lock the list.
2. **Only count links that are actually written.** If two ideas just sit next to each other, don't add the link you think the writer meant.
3. **Read the essay once, from start to finish.** Read it with deletions visible but without any pause information. Give each idea one of four labels:
   - from the plan (first time it appears),
   - a repeat,
   - new but only explaining or giving an example,
   - new and adding something.
4. **Check each link in the essay.** If the list already has the same two ideas joined in the same way and the same direction, it is old. Otherwise it is new. Add everything to the list as you go, including text the writer later deleted.
5. **Let the computer check the pauses.** A new link counts as a discovery only if both ideas already existed before the writer's last pause, and the link is more than a simple "and".
